## 🚀 ¿Qué es CoffeTTP?

**CoffeTTP** es un **cliente HTTP de línea de comandos (CLI)** creado con un objetivo claro:

> 👉 **Hacer simples las peticiones HTTP**

Sin configuraciones pesadas, sin interfaces gráficas innecesarias y sin abstraer de más lo que debería ser explícito.  
Ideal para estudiantes, desarrolladores y entornos donde prima la claridad sobre la sofisticación.

> Proyecto **open source**, enfocado en simplicidad y aprendizaje.  
> ⚠️ Actualmente en desarrollo activo (**IN PROGRESS**).
